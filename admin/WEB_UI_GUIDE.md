# Web 管理界面使用指南

## 概述

Job Flow 提供了一个轻量级的 Web 管理界面，用于管理分布式任务调度系统。界面采用纯 HTML/CSS/JavaScript 实现，无需额外的前端构建工具，保持系统的轻量特性。

## 访问方式

启动 Admin 服务后，在浏览器中访问：
```
http://localhost:8080
```

## 功能模块

### 1. 任务管理

**功能说明**：
- 查看所有任务列表
- 创建新任务
- 启动/停止任务
- 立即执行任务
- 查看任务详情
- 删除任务

**创建任务示例**：
1. 点击"新建任务"按钮
2. 填写表单信息：
   - 任务名称：例如 "数据同步任务"
   - Cron 表达式：例如 "0 0/5 * * * ?" (每 5 分钟执行一次)
   - 处理器信息：例如 "com.worker.handle.DemoJobHandle"
   - 调度策略：选择轮询、随机、哈希或指定 Worker
   - Worker Tag：可选，用于标识特定的 Worker 组
   - 参数：JSON 格式的任务参数
   - 最大重试次数：失败后的重试次数
   - 重试间隔：重试之间的等待时间（毫秒）

3. 点击"保存"

**操作说明**：
- **详情**：查看任务的完整配置信息
- **启动/停止**：切换任务的启用状态
- **执行**：立即触发任务执行一次
- **删除**：永久删除任务（需确认）

### 2. 工作流管理

**功能说明**：
- 查看所有工作流
- 创建工作流（DAG）
- 启动工作流
- 查看工作流详情
- 删除工作流

**创建工作流示例**：
1. 点击"新建工作流"按钮
2. 填写表单信息：
   - 工作流名称：例如 "ETL 数据处理流程"
   - DAG 定义：JSON 格式的有向无环图定义
   - 参数：工作流级别的参数

3. DAG 定义示例：
```json
{
  "nodes": [
    {
      "id": 1,
      "jobId": 100,
      "name": "数据抽取"
    },
    {
      "id": 2,
      "jobId": 101,
      "name": "数据转换"
    },
    {
      "id": 3,
      "jobId": 102,
      "name": "数据加载"
    }
  ],
  "edges": [
    {"from": 1, "to": 2},
    {"from": 2, "to": 3}
  ]
}
```

4. 点击"保存"

**操作说明**：
- **详情**：查看工作流的 DAG 结构和配置
- **启动**：启动工作流执行，返回工作流实例 ID
- **删除**：永久删除工作流（需确认）

### 3. 任务实例

**功能说明**：
- 查看任务执行实例
- 按任务 ID 或状态筛选
- 查看实例日志
- 停止运行中的实例

**状态说明**：
- **等待接收**：任务已分发，等待 Worker 接收
- **运行中**：任务正在执行
- **成功**：任务执行成功
- **失败**：任务执行失败
- **暂停**：任务被暂停

**操作说明**：
- **日志**：查看任务执行的详细日志
- **停止**：强制停止正在运行的任务

### 4. 实时监控

**功能说明**：
- WebSocket 连接状态监控
- 实时接收任务状态变更事件
- 查看事件日志

**使用方法**：
1. 点击"连接 WebSocket"按钮
2. 连接成功后，会实时显示任务相关事件
3. 事件日志显示最近 50 条记录

## 调度策略说明

### 1. 轮询（Round Robin）
按照 Worker 列表顺序依次分配任务，确保负载均衡。

### 2. 随机（Random）
随机选择一个可用的 Worker 执行任务。

### 3. 哈希（Hash）
根据任务 ID 或其他参数的哈希值选择 Worker，保证同一任务总是在同一个 Worker 上执行。

### 4. 指定 Worker
在"指定 Worker"字段中指定特定的 Worker 地址，任务只会在这些 Worker 上执行。

## Cron 表达式示例

```
0 0/5 * * * ?     每 5 分钟执行一次
0 0 0 * * ?       每天 0 点执行
0 0 12 * * ?      每天 12 点执行
0 0 0 1 * ?       每月 1 号 0 点执行
0 0 0 ? * MON     每周一 0 点执行
0 30 10 * * ?     每天 10:30 执行
```

## 技术栈

- **HTML5**：结构化页面内容
- **CSS3**：响应式布局和美观样式
- **Vanilla JavaScript**：无框架依赖的纯 JS 实现
- **WebSocket**：实时通信
- **REST API**：与后端交互

## 注意事项

1. **网络连接**：确保浏览器能够访问 Admin 服务的 8080 端口
2. **跨域问题**：如果前端部署在不同域名，需要配置 CORS
3. **浏览器兼容性**：建议使用现代浏览器（Chrome、Firefox、Edge、Safari）
4. **WebSocket 连接**：部分企业网络可能会阻止 WebSocket 连接，请检查防火墙设置
5. **JSON 格式**：填写参数和 DAG 定义时，确保 JSON 格式正确
